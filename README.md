# 📅 Academic Scheduling AI Agent (Final Project)

## 🚀 Overview

An AI-powered academic scheduling assistant that helps students manage their schedules, assignments, and daily planning efficiently using natural language.

---

## 🔧 Features

* 🤖 AI-based scheduling using natural language
* 📅 Google Calendar integration
* ⚠️ Conflict detection with smart suggestions
* 📚 Assignment tracking with deadlines
* 🧠 Daily planner and study session recommendations
* 🏫 Semester template and holiday handling

---

## 🧠 Tech Stack

* Python
* Streamlit
* LangChain
* Google Calendar API
* SQLite
* Groq (LLM)

---

## ▶️ How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

---

## 🌐 Deployment

[Open Web App](https://academic-scheduling-agent-mxbnsk8iszngnffbyimz6w.streamlit.app/)
> Note: Full Google Calendar functionality is available in the local setup. The deployed version focuses on UI and AI features due to OAuth limitations on Streamlit Cloud.
